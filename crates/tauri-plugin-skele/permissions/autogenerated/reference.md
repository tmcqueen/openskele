## Default Permission

Lets a webview render the workbench and drive it through its commands.

#### This default permission set includes the following:

- `allow-snapshot`
- `allow-subscribe`
- `allow-execute-command`
- `allow-view-children`
- `allow-config-sections`
- `allow-config-set`
- `allow-terminal-attach`
- `allow-terminal-write`
- `allow-terminal-resize`
- `allow-terminal-close`
- `allow-document-open`
- `allow-document-set-text`
- `allow-document-save`
- `allow-output-channels`
- `allow-output-read`
- `allow-output-clear`
- `allow-layout-set-active-container`
- `allow-layout-set-active-panel`
- `allow-layout-close-panel`
- `allow-chrome`
- `allow-window-start-drag`
- `allow-window-minimize`
- `allow-window-toggle-maximize`
- `allow-window-close`
